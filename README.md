# Face Object Detection Project

Personal object detection project using **Ultralytics YOLO**.  
The goal is to train a model that can detect and recognize **me** in images.

## Project Goal
Train a custom YOLO model on a dataset of my own images so the model can locate and identify me in new pictures under different conditions.

## Tools & Technologies
- Python
- Ultralytics YOLO
- Jupyter Notebooks
- scikit-learn (Linear & Logistic Regression)
- Ollama + Llama 3.2 1B
- Google Drive

## Repository Structure
- `notebooks/` → Practice notebooks
- `requirements.txt` → Project dependencies
